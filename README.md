# Techfest IIT Bombay 2026 – Cyborg Landing Page

Open `index.html` in a browser (needs internet for Tailwind CDN + Google Fonts).

- `css/styles.css` – design tokens, effects, components
- `js/tailwind-config.js` – Tailwind theme extension
- `js/main.js` – data (FEST_DATE, EVENTS, STEPS, SPONSORS), countdown, filters, particles, reticle
